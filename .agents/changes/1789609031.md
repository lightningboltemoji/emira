# Veil unfocused windows by default

> Change `1789609031` — 2026-09-16

## Goal

`[focus] unfocused-opacity` and `unfocused-blur` shipped off (`1` and `0`). The defaults are now the values
in use day to day: `0.5` and `8`.

## Implementation

Only the `Config` initializer's defaults change; `emira.example.toml` is regenerated from the schema. The
`unfocusedOpacity` doc comment drops its argument for off-by-default along with the default it justified.

With scrims on, the post-pass emits `.setScrims` whenever focus or a window's frame changes the set. Six
reducer tests built on the default config asserted an exact effect list (`isEmpty`, or `focus` + `raise`);
they now expect the scrim update alongside, as `RulesTests` already does for `.setHoists`, rather than
switching the setting off to keep their lists short. `ScrimTests`' default-is-off test becomes an
opacity-`1`-is-off test.

## Observations

A new user's unfocused windows are now see-through and frosted on first launch. The reasoning that kept
them off — a window manager should not change how apps look unasked — is given up deliberately.
