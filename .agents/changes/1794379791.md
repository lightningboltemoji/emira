# The onboarding wordmark is drawn, not played

> Change `1794379791` — 2026-11-10

## Goal

The onboarding window's heading played a pre-rendered animated WebP: 590×170 at 120 fps, 1.9 MB, which
was 12% of the app on disk and 29% of the release zip, since the WebP was already compressed and the
executables are not. It also cost a resource bundle, plus the code around one: a `Bundle.module`
workaround, a failable `Wordmark.init?`, a `cp` and two comment blocks in the Makefile on why that bundle
is copied but must never be signed, and a test suite for finding the file. The picture is five rounded
rects, a two-stop gradient, a drop shadow, five monoline glyphs and a critically damped spring. All of
that is cheaper to draw than to ship.

## Implementation

`WordmarkScene` ports `.github/logo/scene.ts` to Swift. It's pure: the script, the strip and its commands,
`place`, the carried-velocity timeline, letter sizing, and the glyphs in x-height units.
`windows(at:)` returns every window as drawn, in draw order, the same record `scene.ts` now exports as
`windows(t)`. `frame(t)` became SVG over that record, refactored without changing output: all 1080
frames' SVG compared identical before and after. The spring is `EmiraMotion`'s `Spring.step` at
`k = 320, ζ = 1`, the same closed form as `scene.ts`'s.

`Wordmark` draws it with a layer tree per window: a group carrying opacity (`allowsGroupOpacity`, so a
dimmed window fades as one picture, like SVG's `<g opacity>`), a shadow caster on a `shadowPath`, a
corner-clipped `CAGradientLayer`, and two shape layers for the ink. The clock is the one the WebP player
had, a `CADisplayLink` that asks for the instant the refresh will reach the glass. A refresh whose
windows, rounded to 1/100 pt, match what's up commits nothing, so the holds cost no render-server work.
It honours Reduce Motion by showing the rest frame, as `PulseButton` already did. The WebP didn't.

**The two descriptions are pinned to each other.** `scene.ts` stays the design tool: it has the live
preview, it renders the README's copy, and the demo studio's backdrop draws `frame(t)`. So `bun run ship`
now writes `Tests/EmiraShellTests/WordmarkGolden.swift` from `windows(t)`: every window at two instants
of each step, mid-motion and landed, 24 instants in all. `WordmarkSceneTests` fails until the port agrees
within 0.001 pt. A loop change that only reaches one side becomes a failing test, not a drifting logo.
Two more tests pin what the README promised: the loop closes, and the `e` never moves.

**Glyphs are stroked, not outlined.** The first cut filled `copy(strokingWithWidth:lineJoin: .round)`
outlines, and the `e` came out bevelled where the bar turns into the bowl. A 600 px render showed CG's
own `strokePath` rounding that join and its stroke-to-path output not. So `pen` is a `CAShapeLayer`
stroking the centreline at `0.19 × size` with round caps and joins, and the `i`'s dot is a second,
filled layer. Each arc is built as its own path and then appended with `addPath`. `addArc` on a path
that already has a current point joins it with a line, even an empty one.

Measured against the WebP it replaces, both hosted in one on-screen window (the WebP as `contents`, the
way the old view showed it) and captured with `screencapture -l`: PSNR 46.5 dB over the rest frame on
white and on dark. Shadow falloff matches in width, and native is at most 6/255 darker at a window's edge.
A full loop filmed on screen showed every step, including `i` passing over `r` and the stacked `i`/`r`.
The test process ran at about 2% of one core while animating at 120 Hz.

## Observations

- Two implementations of one loop, held together by the golden rather than shared code. Sharing would
  need the README's WebP rendered from Swift or the app running JS, and neither is worth it for a logo.
  The golden only bites if `ship` is run after a `scene.ts` change. `.github/logo/README.md` says so.
- Validated in a standalone window and as a layer tree, not inside a live onboarding session. Opening one
  needs a missing grant and would prompt on this machine. The integration is the same stack-view call
  with the optional removed.
- `scene.ts`'s `FPS` is now the README's 60, since that's the only file it renders. `ship` rewrote
  `logo.webp` byte-identically.
