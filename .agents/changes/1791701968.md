# One tolerance namespace

> Change `1791701968` — 2026-10-10

## Goal

`ASSESSMENT.md` A6. There were seven near-equality checks with five tolerances, each written out per edge
in its own file:

| Check | Tolerance |
| --- | --- |
| `Engine.approximatelyEqual` | 0.5 |
| `AXExecutor`'s landing report | 1 |
| `AXWindow.sameFrame` | 1 |
| `WindowIdentity.sameFrame` | 2 |
| `SurfaceCache.sameSize` | 2 |
| `approximatelyEqualSize`, `…Scalar` | 0.5 |
| `SizeCorrection`'s question matching | 0.5 |
| `Strip.visibilityTolerance` | 0.5 |

The spread is what hid P8: two checks that had to agree read two different numbers. Two relations were
stated only in prose. `ParkingLot.stagger` and `Stack.minimumStagger` "must clear WindowRegistry's ±2 pt",
and nothing checked that.

## Implementation

**`Tolerance` (in `Geometry.swift`) names each threshold by what it compares** and says why it is that size:

| Name | Value | What it compares |
| --- | --- | --- |
| `placement` | 0.5 | the reducer's diff, the executor's landing report, correction matching, scroll-offset equality and strip visibility; P8 introduced it |
| `landing` | 1 | the writer's one corrective size → position pass; within a point is an app's rounding, which a second pass would only repeat |
| `identity` | 2 | the window-list join and tab succession, which absorb the rounding between two subsystems describing one frame |
| `still` | `identity` | a kept still's size match, the same rounding between what AX answered and what ScreenCaptureKit filmed |

**`Rect.isClose(to:within:)` (from P8) and a new `Size.isClose(to:within:)` are the only per-edge bodies.**
`WindowIdentity.sameFrame`, `SurfaceCache.sameSize` and Engine's three private helpers are now one-line
wrappers that name their tolerance. `AXWindow.sameFrame` is gone; `place` reads `Tolerance.landing` directly.
`WindowIdentity.frameTolerance` is gone; `Strip.visibilityTolerance` is now `Tolerance.placement` by name.
Engine's two bare `0.5`s, the shrink test and the park floor's drop, read `Tolerance.placement`.

**The relation the documents stated is now a test** (`aNubStepClearsTheIdentityJoinsSlack`). The parking
lot's `stagger` and `laneStep`, and `Stack.minimumStagger`, each exceed `Tolerance.identity`.

No value changed, so the suite passed with no expectation moved.

## Observations

- `Engine.approximatelyEqual`, `…Size` and `…Scalar` were kept as private wrappers. They have 30 call sites,
  and `approximatelyEqual(a, b)` reads better than `a.isClose(to: b, within: Tolerance.placement)` at each.
- `Tolerance.placement < Tolerance.landing` is not a relation anything depends on. Each says why it has its
  own value instead.
