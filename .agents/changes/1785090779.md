# `fullscreen`

> Change `1785090779` — 2026-07-26

## Goal

Toggle the focused column between its own width and 100% of the content area. Not macOS's native full
screen, which opens a Space whose animation we cannot cover.

## Implementation

Everything above `Layout.resolvedWidth` already existed: the reducer's case is one call into
`resizeFocusedColumn`, the body `cycle-width` and `grow`/`shrink` share, so the transition, the animated
column width, the two-geometry scope, the mid-flight interrupt and the no-cover degradation came with
it. No `Effect`, `Event` or subsystem was added.

`isFullscreen` **shadows** `widthOverride`, which shadows `widthPreset`; nothing below is modified by
anything above. Consequence: coming off needs no stored state and no restore policy. A column grown to
40% resolves to 40% again, and one on a ladder rung to that rung, re-resolved against the presets as
they are at that moment — so a config reload or display change under a raised fullscreen produces a
live answer rather than a stale point count. The alternative (save the intent, restore it) has to
define what a saved 500 pt means after the ladder is rewritten.

`setWidthPreset` and `setWidthOverride` both clear the flag. Left set, the width the user asked for is
shadowed by an invisible number and the next `shrink` on a column already at 100% moves nothing.
Cleared, the press is continuous, since the delta comes off the resolved width: `shrink 10%` off a
fullscreen column lands on 90% on the first press.

## Observations

- 100% is the **content** width, the same 100% the ladder's top rung and `grow`'s ceiling resolve
  against, so the outer margin still shows. Edge-to-edge was declined: the strip's origin is
  `contentArea.minX` and every column's position accumulates from there.
- Not exclusive, and column-scoped. Two fullscreen columns is two full-width columns, which `grow`
  already reaches. With stackmates it maximizes the column, so both windows stay on screen at half
  height. A solo-window fullscreen needs a per-window height selection, which does not exist.
