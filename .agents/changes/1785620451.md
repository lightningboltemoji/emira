# Test files named by their subject, not sectioned by comment

> Change 1785620451 — 2026-08-01

## Goal

`EngineTests.swift` had grown to 3817 lines and `LayoutTests.swift` to 1603, and both were organised
internally by `// MARK:` headers — 50 of the project's 430. A file that long is past what a reader (or
a model) holds in one pass, so every edit to it is made with partial sight of the whole: the cause of
the fixtures stranded mid-file, and of assertions that drift out of the section they belong to. The
`MARK` headers were the symptom rather than the disease; removing them without splitting the files
would have deleted the only structure those files had.

## Implementation

`LayoutTests.swift` turned out to already hold six independent top-level suites with no shared state,
so it split mechanically into `StripTests`, `PresetTests`, `ColumnTests`, `ParkTests`, `LayoutTests`
and `OuterGapTests`. The inner `LayoutTests` stays whole at 802 lines: its `fourColumns()` helper is
used by every section of it, so splitting further would mean hoisting a shared helper to buy a file
that is already readable in one pass.

`EngineTests` was harder, because 156 lines of `static` fixtures pinned it together — roughly a
thousand `Self.booted(…)` / `Self.snapshot(…)` call sites. Three options:

- **Free functions at module scope.** Dead on arrival: `booted`, `settle`, `run`, `world`, `snapshot`
  and `approx` are each independently defined, with different signatures, in `GhostWindowTests`,
  `RuntimeTests`, `TeardownTests`, `GuideRingTests`, `SocketServerTests` and `GuideModelTests`.
- **Nested `@Suite` structs.** Real hierarchy, but `Self` inside a nested suite names the nested type,
  so every call site breaks anyway.
- **A fixtures protocol**, whose extension statics stay reachable through `Self` in each conforming
  suite. This compiles (including default arguments like `display: Rect = displayFrame`) and needs no
  edit to any test body — but it is a mixin whose empty protocol exists only to inject scope, and it
  forces `static let` to become recomputed `static var`.

The boring option won: `enum EngineFix`, a plain namespace, with `Self.x` rewritten to `EngineFix.x`.
The churn is mechanical and the suite proves it; the indirection is one anyone can read. Nine suites
now carry the reducer scenarios, largest 688 lines. Fixtures used by one suite moved into it
(`stackedStrip`, `twoColumns`, `detentPair`, …); `LatentWorld` stayed shared because
`WorkspaceCommandTests` drives it too.

Across the rest of the tree, 219 `MARK`s that were bare noun phrases restating the declaration beneath
them are gone, and 183 carrying an actual claim — `CF bridging (the +1/+0 boundary)`, `A refused write
invalidates the optimistic frame it was supposed to confirm` — kept their words as plain comments.
The distinction is whether deleting the line loses information.

## Observations

Test identifiers changed: `EngineTests.foo` is now `EngineFullscreenTests.foo` and friends, so any
`--filter` outside the repo needs updating. Nothing in-tree filters by suite name.

The split was driven by a script rather than by hand, and the guard was the suite: 1163 tests before,
1163 after, with the function inventory diffed for exact equality across the rewrite. Two things the
first pass got wrong and the compiler caught — a fixture calling its siblings unqualified once it left
the type, and continuation lines that had been aligned to a paren whose column moved — are the parts
worth re-checking if this is ever done again.
