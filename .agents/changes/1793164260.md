# A window standing where it was sent has landed

> Change `1793164260` — 2026-10-27

## Goal

Every click anywhere on the desktop wrote Zoom's home window again: five clicks, five `setFrame`, five
`axFailed`. Its `AXSize` is not settable, and writing even the size it already has returns
`kAXErrorFailure`; `AXWindow.place` folds every setter's result into `accepted`, and `AXExecutor` confirmed a
landing only on `accepted`. So a window standing exactly where it was sent was reported as a refusal, marked
unverified, and placed again on the next event — and while that write is in flight the uncovered display
holds its veil (`World.inFlight`), so the veil waited on Zoom's main thread after every click.

## Implementation

`AXExecutor.report` confirms a landing whose read-back is where it was sent, within `Tolerance.placement` —
the threshold its drift check already uses — whatever a setter returned. A refusal that drifted, and a landing
with no read-back, are still `axFailed`, so nothing `World.unverified` exists for is lost. Rejected: skipping
the size write when the size already matches, which costs a read on every placement of every window to save
a write on a few.

## Observations

The same five clicks now write nothing. Unit test: a refused setter with an exact read-back is `axLanded`.
