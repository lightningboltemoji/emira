# A window opened after boot is an arrival, whichever scan finds it

> Change `1793164257` — 2026-10-27

## Goal

Of the first five IntelliJ SSH prompts, two were announced `wasAlreadyOpen: true` and **tiled** — the
relational matchers (`smaller-than-focused`, `from-focused-app`) answer "no" for a window emira met mid-life,
so the user's float rule never fired, and an 898-pt column holding a 185-pt dialog scrolled into view. The
watcher trace showed the race: the birth scan goes out on `windowAppeared`, AX does not list the window yet,
the retry is 150 ms away — and the 3 s heartbeat, seeing an unmanaged window on the glass, scans the app with
`alreadyOpen: true` and adopts the prompt first. Zoom, which keeps many unmanaged windows on the glass and is
scanned by the heartbeat constantly, had its device-test dialog and its meeting window found the same way.

## Implementation

Provenance is read off the window rather than off the scan's question. The boot scan records the highest
window number the window server had issued (`WorldWatcher.bootWatermark`; numbers are issued in order), and a
window a met-kind scan finds is still an arrival if it is numbered above that and the heartbeat has not yet
seen it standing unmanaged for a whole round (`isNewborn`, from the `unaccounted` count it already keeps).
That keeps what the "merge toward met" rule exists to protect — a window somebody may already be using is not
snapped or sent anywhere — while a window opened now gets the rules an arrival gets, which is the asymmetry
`PRINCIPLES` §4 draws at boot.

Rejected: tracking pending birth scans per app and preferring them. It covers the IntelliJ race and not the
deaf app or the accessory app reconciliation finds, and it is another latch where a fact the window server
already hands over (the number) answers all three.

## Observations

Seven watcher tests pinned the old reading. Each now gives its "already open" window a number listed at boot
(off the glass, or undescribed by AX) — keeping what it tested: the flag riding the retry chain, the
coalesced replay, the stray path for an accessory app — and two new tests cover the newborn and the
stood-a-round cases. Live: three IntelliJ prompts in a row floated; Zoom's dialog and meeting window, found by
met-kind scans, arrived as arrivals.

A window created after boot but kept off the glass for a long time (another Space) is an arrival when it
first shows, rules and all.
