## Implementation

`README.md` states the approach: macOS window managers move windows over the Accessibility API, whose
latency varies from ~10 ms to ~300 ms per action, and that variance is what produces perceived jank.
emira animates a compositor overlay — screenshots of the windows — while the real windows are placed
underneath, which gives fixed-cost animation and hides the AX latency. It credits the project's
inspirations, and records that the code was written by Claude and the prose was not.

The source comments were pared back in the same commit.

## Observations

No install instructions, no configuration reference, and an empty `# about` section. emira is not
distributed: signing is ad-hoc, so following an install section today means re-granting Accessibility
and Screen Recording on every rebuild. The config surface is documented only in `IMPLEMENTATION.md` §6.
